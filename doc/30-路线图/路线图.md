# 路线图

## 当前版本

`v0.4.0` 已发布：`/reminders` 收敛为“空参确定性列表 / 非空交回当前 Pi session”的极简路由；旧别名与手写动词解析已移除。

## v0.5.0（规划中）

### 列表阅读

改善空参 `/reminders` 的高频阅读体验，优先讨论筛选、排序和限量语义；不在未对齐前实现多清单管理。

### 批量删除的一次确认

当 LLM 需要删除多条 reminder 时，目标流程是：

```text
逐个解析目标 → 展示待删摘要与未解析项 → 一次确认 → 尽力删除已解析项 → 返回逐条结果
```

已解析的目标在确认后尽力删除；未找到、歧义取消或执行失败的目标不阻塞其余项目，并在结果中逐条说明。实施以 [`../40-版本实施方案/v0.5.0-列表阅读与批量删除确认.md`](../40-版本实施方案/v0.5.0-列表阅读与批量删除确认.md) 为唯一权威方案，内置 checklist（检查清单）。

## 后续候选

- 多清单管理：仅在现有默认清单模型确实不足时再规划。
- 安装与 marketplace（市场）发布体验：在能力边界稳定后完善。
