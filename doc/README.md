# 文档地图

`doc/` 是 pi-reminders 的项目知识库。当前采用按职责编号的目录地图；术语表和决策档案保留在根目录，便于稳定引用。

## 阅读顺序

1. `00-产品与原则/产品定位与原则.md` — 项目定位、体验与职责边界。
2. `10-架构与运行/架构与运行.md` — 当前命令路由、tool、数据通道和验证方式。
3. `30-路线图/路线图.md` — 版本计划的唯一权威。
4. `40-版本实施方案/v0.5.0-列表阅读与批量删除确认.md` — v0.5.0 的唯一实施方案与验收 checklist。
5. `术语表.md` — 项目特有术语。
6. `决策档案/README.md` — 难逆转决策的索引与追溯入口。

## 目录与权威性

| 位置 | 职责 | 权威性 |
|---|---|---|
| `00-产品与原则/` | 产品定位、体验与职责边界 | 长期有效权威 |
| `10-架构与运行/` | 当前实现、运行与测试方式 | 当前实现权威 |
| `30-路线图/` | 版本维度编排 | 路线图唯一权威 |
| `40-版本实施方案/` | 版本级实施方案与验收 checklist | 受路线图约束的实施权威 |
| `术语表.md` | 项目特有概念定义 | 术语唯一权威 |
| `决策档案/` | 难逆转设计决策 | 决策追溯权威 |

当前没有实际内容，因此不创建 `20-能力参考/` 或 `90-归档/`。未来出现外部能力事实或过时方案时，再惰性创建对应目录。
