# 0002 — LLM 负责意图理解，并分离慢速回归

- 状态：已采纳
- 日期：2026-07-10

`/reminders` extension 只负责命令路由：空参直接列出待办，非空文本交回当前 Pi session。LLM 负责把自然语言理解为 `reminders` tool 的 action 与参数，tool 负责执行已结构化的请求；extension 不为批量、update 或模型空回复补建理解/重试逻辑。

回归保留一个有界的真实 Pi RPC handoff smoke（转交冒烟测试）证明非空文本能交回 Pi 并启动 agent；具体 action 的选择和 tool 执行属于 LLM 运行时职责，不由 smoke 观察模型响应。模型额度、速度、批量解释和多字段 update 属于慢速环境验证，不作为产品 phase 的同步建检门槛。这样保留真实转交验证，避免把模型服务波动和审核器时限混入极简 extension 的实现范围。
