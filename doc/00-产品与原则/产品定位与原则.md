# 产品定位与原则

## 定位

pi-reminders 是一个 macOS 专用的 Pi extension（Pi 扩展）：通过系统 `osascript` 操作 Apple Reminders，为用户提供常驻的 `/reminders` 工作流。

## 核心体验

- 空参 `/reminders`：零 LLM（大语言模型）成本地确定性列出默认清单 `近期待办`。
- 非空 `/reminders <自然语言>`：extension 只把原文本交回当前 Pi session；LLM 负责意图理解、`action` 选择与参数填写。
- `reminders` tool（工具）：接收结构化 action 后执行实际操作。

## 边界

- 只支持 macOS 与系统自带 `osascript`；不引入 MCP、数据库、云同步或后台服务。
- 人类入口只有 `/reminders`；不恢复别名或手写动词解析。
- 默认清单固定为 `近期待办`，修改前必须同步入口 README。
- `add` / `complete` 直接执行；`delete` 保持单次确认。
- extension 不为模型空回复、模型额度、批量理解或跨 session 行为补建兜底逻辑。
