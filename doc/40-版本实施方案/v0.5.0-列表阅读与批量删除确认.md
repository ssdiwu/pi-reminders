# v0.5.0：列表阅读与批量删除确认

- 状态：已对齐，待实现
- 路线图：[`../30-路线图/路线图.md`](../30-路线图/路线图.md)
- 实施方案权威性：本版本唯一实施方案

## 目标

让 `/reminders` 的高频读取更聚焦，并让一次 LLM（大语言模型）批量删除在一份清晰摘要后只确认一次。保留 v0.4 的极简命令路由：空参确定性列表，非空文本交回当前 Pi session。

## 范围与边界

### 包含

1. 扩展 `reminders(action="list")`：标题检索、到期窗口、到期日排序与 `limit`（限量）。
2. 扩展 `reminders(action="delete")`：一批目标在一次确认后尽力删除已解析项目。
3. 为新结构化契约补充 prompt、文档与可复验测试。

### 不包含

- 不新增 slash command（斜杠命令）别名、flags 或手写解析。
- 不做已完成历史、多清单管理、批量 complete（完成）。
- 不把模型 action 选择、额度、跨 session 行为纳入 extension 回归。
- 不创建会写入默认 `近期待办` 的自动测试夹具。

## 用户可感知契约

### 列表阅读

- 空参 `/reminders` 仍列出默认清单全部未完成项。
- 非空自然语言继续由 LLM 转成 `reminders(action="list")`；人类入口不解析筛选条件。
- `query` 沿用当前标题包含匹配。
- 新增可选 `dueFrom` / `dueTo`：绝对闭区间。日期值按当天 `00:00` / `23:59` 归一化；精确到分钟的值按该分钟包含。指定任一边界时，无到期日项不进入结果。
- 所有结果先按到期日升序排序，再放无到期日项；`limit` 是正整数，省略时不截断。

### 批量删除的一次确认

- 单条 `query` 继续可用；多目标走内部新增的 `queries` 数组，不增加新的 action。
- 每个目标独立解析：精确 ID 优先；标题匹配多条时逐条让用户选择；未找到或取消选择记为未解析。
- 已解析项目按 reminder ID 去重。没有已解析项目时不显示确认框。
- 确认摘要同时列出“将删除”与“未解析项及原因”；用户取消最终确认时，不删除任何项目。
- 用户确认后顺序尝试删除所有已解析项目；任一执行失败不阻塞其余项目。结果逐条返回已删除与未删除原因。

## 实施切片

### 切片 1：结构化列表阅读

- 扩展 `RemindersParams` 和 tool 描述，明确日期必须是绝对值、`limit` 必须为正整数。
- 将过滤、排序、限量集中在列表读取路径：先保留现有未完成与标题匹配，再应用到期窗口、排序、限量。
- 保持 `/reminders` 空参调用同一路径，不恢复参数解析。

### 切片 2：批量删除确认

- 提取“多引用解析、已解析目标去重、未解析原因记录”的内部流程。
- 用批量确认摘要替换逐条 `confirmAction()`；最终确认前不调用删除。
- 顺序执行删除并捕获每条错误，返回完整结果。
- 维持单条 delete 行为与原有 `query` 调用兼容。

### 切片 3：文档与验证

- 同步 README、`10-架构与运行/`、路线图和 tool prompt。
- 保留现有真实 RPC 命令路由 smoke，不为模型理解加重试或行为矩阵。
- 为列表的筛选/排序/限量和批量结果聚合建立确定性测试；真实 mutating（写入）回归仅允许使用显式 `REMINDERS_LIST` 指定、且名称不是 `近期待办` 的用户授权 sandbox（沙盒）清单。测试按精确创建 ID 清理，结束时验证清单中无本轮 fixture（夹具）。

## 验收 checklist

### 列表阅读

- [ ] `action=list` 接受并校验 `dueFrom`、`dueTo` 与正整数 `limit`。
- [ ] 默认列表只返回未完成项，保留无到期日项。
- [ ] 存在到期窗口时，无到期日项被排除，日期边界按闭区间处理。
- [ ] 结果按到期日升序、无日期置后，并在排序后应用 `limit`。
- [ ] 空参 `/reminders` 不新增 agent/tool 调用，也不恢复人工 flags。

### 批量删除

- [ ] 单条 `query` delete 保持可用。
- [ ] 多目标只触发一次最终确认，确认摘要同时显示待删与未解析项目。
- [ ] 未解析或执行失败的目标不阻塞其余已解析项目。
- [ ] 取消最终确认不会删除任何项目。
- [ ] 返回逐条的成功与失败原因，且同一 reminder 不重复删除。

### 验证与发布准备

- [ ] `npx tsc --noEmit` 通过。
- [ ] `python3 scripts/test-extension-rpc.py` 通过。
- [ ] 新增的确定性测试覆盖列表结果语义与批量结果聚合。
- [ ] 如运行真实写入回归：只使用用户授权 sandbox 清单，按精确 ID 清理并复查无遗留 fixture。
- [ ] README、架构文档、路线图、术语表和 CHANGELOG 的用户可见说明同步。
