# pi-reminders 术语表

## 命令路由

`/reminders` extension 对空参和非空参数作出的入口分流：空参直接列出待办，非空文本交回当前 Pi session。

## 意图理解

LLM 将用户的非空自然语言映射为 `reminders` tool 的 `action` 与结构化参数的过程。不属于 extension 的职责。

## Tool 执行

`reminders` tool 根据已结构化的 `action` 调用 AppleScript 操作 Reminders.app 的过程。

## 批量删除的一次确认

一个 delete（删除）请求包含多个目标时的确认交互：展示已解析的待删 reminder 与未解析目标，再由用户一次确认已解析项目的删除。
