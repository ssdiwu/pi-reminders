# 架构与运行

## 入口与职责

`index.ts` 是唯一运行入口，注册一个 `/reminders` command（命令）和一个 `reminders` tool。

```text
/reminders
├── 空参 → listReminders() → select UI
└── 非空 → pi.sendUserMessage(text)
             └── busy 时 deliverAs: followUp
```

`reminders` tool 保持 `add|list|complete|delete|update` 的结构化 action 契约。LLM 负责把自然语言映射为该契约；tool 再调用数据层执行。

## 列表阅读契约

`action=list` 的结果语义（v0.5.0 新增）：

- `query`：标题包含匹配（既有可能力）。
- `dueFrom` / `dueTo`：绝对闭区间，`YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM`。日期按当天 `00:00` / `23:59` 归一化，精确到分钟的值按该分钟包含。指定任一边界时排除无到期日项；未指定时保留全部未完成项。工具层用 round-trip 日历校验拒绝 `2026-02-30`、非闰年 `02-29`、`24:00` 等无效值。
- 结果先按到期日升序排序，无日期项置后（同值按 ID 稳定）；`limit` 为正整数且在排序后截取，省略时不截断。

## 数据通道

数据层通过逐行 `osascript -e` 调用 Reminders.app。`runOsa()` 保留 120 秒超时和 stderr（标准错误）传播；AppleScript 传输方式的权衡见 ADR 0001。

## 运行与验证

```bash
npx tsc --noEmit
python3 scripts/test-extension-rpc.py
node --experimental-strip-types scripts/test-list-query.ts
```

真实 RPC smoke（冒烟测试）显式加载当前 `index.ts`：

- 空参路径断言默认清单 `select`，且静默窗口内不启动 agent/tool。
- 非空路径断言 handoff response（转交响应）后启动 agent，并通过 `get_messages` 核对精确交回文本。

`test-list-query.ts` 是列表阅读结果语义的纯函数单测：覆盖到期窗口、排序、限量与工具层非法拒绝，不经 LLM、不写真实提醒事项。

它们验证 extension 的命令路由与列表语义，不验证 LLM 如何选择 action 或完成具体 CRUD（增删改查）。
