# 架构与运行

## 入口与职责

`index.ts` 是唯一运行入口，注册一个 `/reminders` command（命令）和一个 `reminders` tool。

```text
/reminders
├── 空参 → listReminders() → select UI
└── 非空 → pi.sendUserMessage(text)
             └── busy 时 deliverAs: followUp
```

`reminders` tool 保持 `add|list|complete|delete|update` 的结构化 action 契约。LLM 负责把自然语言映射为该契约；tool 再调用数据层执行。

## 数据通道

数据层通过逐行 `osascript -e` 调用 Reminders.app。`runOsa()` 保留 120 秒超时和 stderr（标准错误）传播；AppleScript 传输方式的权衡见 ADR 0001。

## 运行与验证

```bash
npx tsc --noEmit
python3 scripts/test-extension-rpc.py
```

真实 RPC smoke（冒烟测试）显式加载当前 `index.ts`：

- 空参路径断言默认清单 `select`，且静默窗口内不启动 agent/tool。
- 非空路径断言 handoff response（转交响应）后启动 agent，并通过 `get_messages` 核对精确交回文本。

它验证 extension 的命令路由，不验证 LLM 如何选择 action 或完成具体 CRUD（增删改查）。
